# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its Code
of Conduct. The canonical text — including the full pledge, standards,
enforcement responsibilities, and scope — is available at:

> https://www.contributor-covenant.org/version/2/1/code_of_conduct/

The summary and the reporting channel below are the project-specific
adoption notes; in any conflict between this file and the canonical
Covenant text, the Covenant text prevails.

## In short

Everyone interacting in this project's spaces — issues, pull requests,
code review, discussions, social channels, and public events where you
represent the project — is expected to:

- Be welcoming and respectful regardless of background, experience, or
  identity.
- Engage with empathy and assume good intent.
- Give and gracefully accept constructive feedback.
- Take responsibility for mistakes, apologise sincerely, and learn from
  them.
- Prioritise what's best for the overall community.

Unacceptable behaviour includes harassment, personal attacks,
discriminatory language, public or private abuse, publishing others'
private information without consent, and any conduct a reasonable person
would consider inappropriate in a professional setting.

## Reporting

Reports of unacceptable behaviour can be sent to
**conduct@slashbuilder.com**. All reports are kept confidential.
Maintainers are obliged to respect the privacy and safety of the
reporter; we will not name a reporter without their consent.

If a maintainer is themselves the subject of a complaint, escalate to
another maintainer or to the contact above with a note flagging the
conflict; the report will be handled by someone not involved.

## Enforcement

Maintainers will follow the **Community Impact Guidelines** described in
the canonical Covenant text — correction, warning, temporary ban,
permanent ban — in determining the consequences for any action they deem
in violation of this Code.

## Scope

This Code of Conduct applies within all project spaces and in public
spaces when an individual is representing the project or its community.
Examples include using an official email address, posting via an official
social media account, or acting as an appointed representative at an
online or offline event.
